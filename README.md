## 🛠️ Tecnologias Utilizadas


### Núcleo (Core)
* **HTML5 CSS3 JavaScript** 

### Bibliotecas Visuais & 3D (CDNs)
* [**GSAP & ScrollTrigger**](https://gsap.com/): Animações focadas nos eixos, interpolamento do tempo ("Preloader"), acompanhamento magnético do rato ("Custom Cursor") e Timeline masks do "Hero text".
* [**Lenis**](https://lenis.studiofreight.com/): Biblioteca focada num Scroll Suave mantendo a compatibilidade do sistema Snap.
* [**Swiper.js**](https://swiperjs.com/): Construção central da secção de projetos sob a forma do inovador Carrossel 3D "CoverFlow".
* [**Vanta.js**](https://www.vantajs.com/) (suportado pelo **Three.js**): Gera o fundo "Neuro-Networking" que interage repulsivamente à passagem mecânica do cursor.
* [**Vanilla-Tilt.js**](https://micku7zu.github.io/vanilla-tilt.js/): Motor responsável pelo efeito de oscilação luminétrica 3D nos contentores ("glass-cards").
* [**Typed.js**](https://mattboldt.com/demos/typed-js/): Máquina de escrever cibernética automática presente por baixo do logótipo principal principal.

### Ícones
* Utilização das CDNs unificadas provenientes de biblioteca **Lucide**, **BoxIcons**, **Bootstrap Icons** e **RemixIcons**.

## 🚀 Como Correr Localmente

Todo o planeamento é assente em dependências CDN abertas de raiz no HTML. Não requeres compiladores.

1. Efetua o Clone deste repositório:
   ```bash
   git clone https://github.com/Migueljfc/Migueljfc.github.io.git
   ```
2. Navega para a pasta do diretório:
   ```bash
   cd Migueljfc.github.io
   ```
3. Podes simplesmente duplo-clicar e executar o `index.html` em qualquer navegador. No entanto, para visualização recomendada usa extensões locais como o *Live Server* ou executa usando ferramentas em Python:
   ```bash
   python -m http.server 5500
   ```
4. Acede localmente no browser através de `http://127.0.0.1:5500`.
